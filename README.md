# Dr. Durai Diabetic Foot Care Website

This is the original website split into separate files for easier maintenance. The existing Tamil content, visual styling, and JavaScript behavior were retained. Embedded image data was moved into `assets/images/` and linked locally.

## Files
- `index.html` — page markup
- `css/style.css` — original stylesheet
- `js/main.js` — original primary script
- `js/floating-contact.js` — original floating call/contact script
- `assets/images/` — extracted embedded images and favicon

## Run
Open `index.html` in a browser. For local development, you can also serve this folder with a simple static server.
